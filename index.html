03 / Deployment

Types of Cloud Computing

P

Public

Public Cloud

Provider-shared infrastructure. A public cloud provides resources to many users online.

  • Cost-efficient
  • Highly scalable
V

Private

Private Cloud

Infrastructure for one organisation. A private cloud is dedicated to a single organisation.

  • Greater control
  • Custom security
H

Hybrid

Hybrid Cloud

Public and private environments together. A hybrid cloud combines public and private environments.

  • Flexible
  • Balanced control

07 / Protection

Security and Challenges

◇

Protected Cloud

Encryption — protects data
Login Security — verifies access
Backup — protects stored copies
Monitoring — tracks activity

Shared Responsibility

Provider: Protect infrastructure.

User: Protect accounts and data.

Shared responsibility divides cloud protection between the provider and the user.

  • Multi-factor login
  • Strong passwords
  • Regular backups
  • Limited access
  • Software updates
